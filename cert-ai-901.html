Section 1

What the exam covers

The exam is split into skill areas. The percentage shows roughly how much of the exam each area makes up, so spend your time to match.

Identify AI concepts and capabilities40–45%
  • Responsible AI: fairness, reliability and safety, privacy and security, inclusiveness, transparency, and accountability
  • Generative AI model concepts, model capabilities, deployment options, and configuration parameters
  • AI workload scenarios: generative and agentic AI, text analysis, speech, computer vision, and information extraction
  • Text analysis techniques: keyword extraction, entity detection, sentiment analysis, and summarization
  • Speech recognition and synthesis; vision and image-generation capabilities; extraction from text, images, audio, and video
Implement AI solutions by using Microsoft Foundry55–60%
  • Create prompts, deploy models, and build lightweight generative AI clients with the Foundry SDK
  • Create and test a single-agent solution and a lightweight agent client
  • Build text-analysis and speech applications using Foundry models and Foundry Tools
  • Use multimodal models for visual input and image generation
  • Extract information from documents, forms, images, audio, and video using Content Understanding in Foundry Tools
Section 2

Key concepts, explained simply

These are the ideas that come up again and again. Open each one and make sure you could explain it to a friend.

Responsible AI

Microsoft's six principles are fairness, reliability and safety, privacy and security, inclusiveness, transparency, and accountability. Be able to identify the principle implicated by a scenario and explain the practical safeguard.

Model selection and deployment

Choose a model based on task, modality, quality, latency, cost, and deployment constraints. Configuration parameters such as temperature and token limits affect output behavior; they do not guarantee correctness.

Text and speech workloads

Know common text-analysis tasks such as key phrase extraction, entity detection, sentiment analysis, and summarization. Distinguish speech recognition (audio to text) from speech synthesis (text to audio).

Computer vision and multimodal AI

Understand image interpretation and image generation, and how multimodal models can combine visual input with text prompts. Match the workload to the model capability rather than assuming every model supports every modality.

Information extraction

Content Understanding in Foundry Tools can extract structured information from documents and forms, images, audio, and video. Plan for validation: extracted fields can be incomplete or incorrect.

Foundry apps and agents

The exam includes hands-on implementation concepts: deploy a model, use the Foundry SDK, create prompts, build a lightweight client, and create/test a single-agent solution. Keep agent tools narrowly scoped and validate their outputs.

Section 3

Study plan

About an hour a day is enough. Adjust the pace to your experience.

  1. Week 1Study AI workloads, model concepts, responsible AI, and model selection. Map each topic to the official skills-measured list.
  2. Week 2Practise text, speech, vision, and information-extraction scenarios. Build small examples and compare service/model choices.
  3. Week 3Use Microsoft Foundry to deploy a model, call it from a lightweight Python client, and create/test a single-agent solution.
  4. Week 4Build a small Content Understanding workflow, review weak areas, and use the current AI Skills Navigator practice assessment and official guide.
Section 4

Exam tips

  • Read every question twice. Many answers are “which service fits this scenario”.
  • Use the AI Skills Navigator practice assessment to identify weak objectives; review the official guide for each missed area.
  • Hands-on practice beats memorising: build what you read about in a free account.
  • Read each question carefully and identify whether it tests a model capability, service choice, or implementation step.
  • Check the official study guide a week before your exam in case the skills changed.
